# MetaMapa — Frontend

Interfaz web de MetaMapa, plataforma para visualización y gestión de
hechos geolocalizados con búsqueda, colecciones y cargas colaborativas.
Desarrollado como TP de **Diseño de Sistemas (UTN FRBA, 2025)**.

Consume la API REST del backend: [metamapa-backend](https://github.com/FrancoVinaccia/metamapa-backend)

## Stack

- Java + Spring Boot (Maven)
- Vistas web renderizadas desde el servidor

## Ejecutar

​```bash
./mvnw spring-boot:run
​```
